# Contributing

Thanks for contributing to `interview`.

## Conventions

- Editor rules live in `.editorconfig` + `.vscode/settings.json`.
- Content goes under the right section (`behavioral/`, `system-design/`, `coding/`, `resume/`).
- Markdown: tables wrapped in `<!-- begin table -->` / `<!-- end table -->`.
- `test.yml` gates pull requests (docker targets `lint` / `resume` / `coding`) — keep it green.

## PR workflow

1. Branch from `main`.
2. Make a focused change.
3. Open a PR into `main`.
